How the four demos differ

They do not. The application code is byte-identical across all four — the same router, the same models, the same components. What changes is a single configuration file that supplies the words on screen, the status labels and which dataset to load. Adding a fifth trade is a config entry and a seed file, not a rewrite.

Front-end prototype of a PHP 8.1 + MySQL application · no framework, no build step, no server · data saved in your browser only
